# AetherWorld LiteRPG System

Fabric target: Minecraft 26.1.2.

Current build includes persistent CCA player data for level, XP, XP requirement, free points, PS, mana and five attributes; level-up rewards; derived attribute effects; INT mana; zero-mana penalties; perception on P; system UI on O; server-side purchase validation; the 10% offhand card discount; Mana Core; Rift Crawler E; Fallen Rune Sentinel E; and Crypt Guardian E.

The custom combat-weapon implementation from the original specification is not part of this first JAR.

Test entity IDs:
aetherworld_litrpg:rift_crawler
aetherworld_litrpg:fallen_rune_sentinel
aetherworld_litrpg:crypt_guardian

GitHub Actions builds the JAR under build/libs/.
